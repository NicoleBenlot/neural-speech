Important commands (run from repo root, always with the venv python: .venv\Scripts\python.exe or `python` if venv is active):

NOTES TO KNOW BEFOREHAND:
- Always use the VENV python (.venv\Scripts\python.exe), never the base D:\python one.
  venv has the GPU torch (cu130); base D:\python has the old CPU build.
- -d auto picks CUDA -> MPS -> CPU for you; fp16 AMP turns itself ON for CUDA.
- Checkpoints auto-prune after every saved epoch: keep = recorded best (best.json)
  + final + best-val-loss + every Nth (--retain-every 10 default). Pass --retain-every 0
  to disable, --retain-protect vNNN to pin. resume only works from a KEPT version.
  Never save into an existing version dir.
- latest != best: latest.json = most recent epoch, best.json = best validation
  performance. best.json tracks both val_loss-min and CER-min independently
  (dataset-aware, can't be shadowed by an older dataset's lower val_loss); prune
  protects both. Use `best` anywhere a checkpoint is accepted: -resume best,
  --from-checkpoint best, --checkpoint checkpoints/mms/best.
- Checkpoints/mms now holds ONLY v026 (best) + v030 (final) = 3.1 GB. Weights are never in git.
- index.txt now supports SENTENCES: "ang bata nagdula sa bola = 196" (multi-word OK, id = filename).
- No audio-length cap; only --max-text-len (default 64) limits decode. Long sentences: raise to 128.
- 6 GB GPU: batch too big = CUDA out of memory (OOM). Drop -b 8 -> -b 4.
- Audio loads via soundfile fallback automatically - real .opus works even without FFmpeg full-shared.
- .venv is NOT portable between PCs - recreate with pip install -r requirements.txt.
  (.venv and checkpoints/ are git-ignored; GitHub never stores them.)
- bash = Git for Windows. New terminals pick it up (C:\Program Files\Git\bin added to user PATH).
- Flash drive D: = "KINGSTONE E". copy_repo.sh pushes/pulls the repo (skips .venv + caches).
  Off-site alternative if you ever need version history: DVC/cloud with the same keep-set policy.
- The 3 training modes are mutually exclusive: pick ONE of -new / -continue / -resume (never combine).

Data prep:
python ns.py prepare                          # index.txt -> data/processed/manifest.csv
python ns.py validate --fail-on-error         # dataset checks

Train - three modes, always pick exactly ONE (-d auto picks CUDA -> MPS -> CPU):
python ns.py train -new -d auto -e 30               # 1) FRESH RUN on current data (rebuilds tokenizer + splits)
python ns.py train -continue -d auto -e 30          # 2) CONTINUE from BEST val-loss version onto NEW data (auto replay + regression)
python ns.py train -continue latest -d auto -e 30   #    same, but parent = newest version
python ns.py train -resume -d auto -e 30            # 3) RESUME the SAME run/data (optimizer/scheduler/epoch/RNG); auto = newest line's latest
python ns.py train -resume <version-or-path> ...    #    explicit resume target (e.g. v026 or checkpoints/mms/v026)
python ns.py train --from-checkpoint <dir> ...      #    manual incremental parent (no auto-wiring)
python ns.py train --help                           # full flag list

Handled for you automatically (no typing needed):
- no -m  -> fb (facebook/mms-300m). Pass -m none for a from-scratch encoder.
- no -c  -> -continue/-resume auto-detect the newest line under checkpoints/ (yours = checkpoints/mms).
- -continue auto-wires --replay-manifest + --eval-manifest from the parent's dataset (ratio 0.3).
- Stale split_*.json files are auto-detected (manifest SHA-256 fingerprint) and re-split when data changes.
- -b defaults to 8; drop to 4-6 on the 6GB GPU if OOM. Pick -e to control run length.

Always-available train flags (long form still works):
--dataset <csv> -b/--batch-size -e/--epochs -d/--device -mtl/--max-text-len
--retain-every N (prune interval; 0 = keep all)   --retain-protect vNNN (pin a version)
--replay-manifest <csv> --replay-ratio 0.3        --eval-manifest <old-csv> (regression)

Short-flag map: -m model backbone (fb/mms/mms-300m = facebook/mms-300m; none = from scratch)
                 -c checkpoint dir (writable line, e.g. checkpoints/mms-sent)
                 -e epochs   -b batch size   -mtl max text len   -d device (auto|cuda|cpu)

Inference:
python ns.py transcribe <audio> --checkpoint checkpoints/mms-sent/latest --device cuda
python ns.py mic --seconds 5                  # live mic test
python ns.py mic --loop --seconds 3           # keep going until Ctrl+C
python ns.py probe --checkpoint checkpoints/mms-sent/latest   # encoder-collapse check

Deploy / env:
python ns.py optimize                         # INT8 quant + ONNX export
python ns.py devices                          # detect compute devices
python ns.py devices --check cuda             # resolve a device string
uvicorn src.api.main:app --port 8000          # FastAPI
python -m pytest tests -q                     # 107 tests
